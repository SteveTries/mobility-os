# Mobility OS exercise assets

Upload all exercise image files into this folder.

Recommended naming pattern:
- `01_knee_to_wall_start.png`
- `01_knee_to_wall_end.png`
- `02_calf_wall_stretch.png`
- etc.

Use PNG or JPG files. Once the files are uploaded here, the app can reference them directly via relative paths such as `assets/exercises/01_knee_to_wall_start.png`.
